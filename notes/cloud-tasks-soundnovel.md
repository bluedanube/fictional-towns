# クラウドセッション用の指示文（3本）

使い方：A と B は同時に走らせてよい。C は A・B のあとに実行する。
各セッションは `main` から始め、作業用ブランチで進める。マージは作者が確認してから行う。

## 共通の前提（3本とも、冒頭に貼る）
```
リポジトリ bluedanube/fictional-towns の設定を使います。先に次を読んでください。
- notes/soundnovel-outline.md（骨子。決定事項は9）
- notes/soundnovel-script-format.md（台本データ形式）
- notes/promise.md、notes/decisions.md、notes/pending-approval.md
- notes/magical-girls.md、notes/customs.md、notes/places.md、notes/layout.md
- towns/ の2ファイル、notes/world-overview.md、notes/forgotten-reason.md

守ること：
- 約束の相手（名前のない子ども）の姿・名前・年齢・性別・声は書かない。席と痕跡だけで示す。
- 次は未決定のまま。決めない、匂わせない：五時十三分に何があったか／番地の数値／縫い街の最初の一針／畳まれた日が開いたときの街／約束の相手のその後／U町・F町の読み方と所属市町村。
- 三つの核（忘れられた理由、縫い街の成り立ち、地理案A）は仮決定。本文では説明しない。
- 少女42人の名前・飾り・魔法は変えない。実在の地名は使わない。
- 悲劇・恐怖・責任追及の話にしない。静かな現在形、短い文、説明しない。
- 迷ったら決めずに、報告の「作者への質問」に書く。
- コミットの末尾に Co-Authored-By と Claude-Session の行を付ける。
```

## A. 章の本文（序・1〜8・終）
```
（共通の前提）

タスク：骨子の表4に従い、script/ch00.json、ch01〜ch08.json、ch99.json を作る。
- 形式は notes/soundnovel-script-format.md に従う。choice は enabled: false の枠だけ。
- 1章あたり本文600〜900字。視点は「わたし」（素性を決めない旅人。相手とは無関係）。
- 各章の終わりは「また、あした」。この言い回しは全章で同じ形にする。
- 各章に、骨子の「席の痕跡」を一つだけ、説明なしで置く。
- 住人は、住人録の職業と記録から外れる行動をさせない。
- 少女は、飾りと魔法の文に沿った小さな所作を一つだけ見せる。魔法効果は大きくしない。
- book: true の行を、章ごとに3〜5行付ける（絵本用）。
- 終章は、灯がともり、全員が「また、あした」と言うところで止める。翌日は描かない。
- 完成後、禁止事項を自分で一度点検し、notes/soundnovel-draft-report.md に
  「章ごとの要点」「決めてしまいかねなかった箇所」「作者への質問」を書く。
```

## B. 試作プレーヤー（HTML1枚）
```
（共通の前提）

タスク：script/ のJSONを読んで動く、サウンドノベル風の試作プレーヤーを player/ に作る。
- 構成：player/index.html（単体で動く。サーバー不要、file:// で開ける）。外部ライブラリは使わない。
- 画面：背景全面、立ち絵（pos: left/center/right）、下部のテキスト窓、住人は小窓のアイコン。
- 操作：クリック／タップ／Enter/Space で次へ、Backspace で戻る、ログ表示。文字は1文字ずつ表示。
- 台本：script/ch*.json を順に読む。ファイルが無い場合は、同梱のダミー台本（player/sample/）で動く。
- 素材が無いとき（missing）は仮の枠と文字で出す。背景は assets/images/sewn-town/*.webp を使う。
- choice.enabled が true の場合に備え、選択肢と「糸」の集計を実装する。ただし既定は無効。
- 音：bgm/se の名前を読むだけ。ファイルが無ければ無音で進む。
- 絵本表示モード：book: true の行だけで、1章を1見開き（背景＋3〜5行）に並べる画面を作る。
- スマホ縦持ちでも崩れないこと。ブラウザで動かして確認し、スクリーンショットを player/screens/ に残す。
- 完了後、動かし方を player/README.md に書く。
```

## C. 点検（A・B のあとで実行）
```
（共通の前提）

タスク：A と B の成果を、書いた側とは別の目で点検する。ファイルは直さず、報告だけ書く。
- script/*.json の全行を読み、禁止事項（共通の前提）に違反する箇所を、ファイル名と行で列挙する。
  特に「匂わせ」に注意：五時十三分の意味、相手の性別が分かる代名詞、番地の数字、来る／来ない を示す語。
- 少女・住人の名前、飾り、魔法、職業が、notes/magical-girls.md と towns/ の表と一致しているか。
- 「また、あした」の言い回しが、全章で同形か。
- JSONが形式に合っているか（スクリプトで機械的に検証し、結果を載せる）。
- player/ が全章を読んで最後まで進めるか（動かして確認）。
- 結果を notes/soundnovel-review.md に書く。重大／軽微／提案に分ける。
```
