## 形式と大きさ
- 形式：WebP（品質90）。見た目を保ちつつ容量を抑えるため。
- 大きさ：長辺1536px程度。元の大判PNG（約2.7MB）から、約0.3MBに縮めています。
- 元の大判画像は作者のMacにあり、リポジトリには入れません。
