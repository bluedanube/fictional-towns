# 画像の置き場

採用した画像だけを入れます。

## 形式と大きさ
- 形式：WebP（品質90）。見た目を保ちつつ容量を抑えるため。
- 大きさ：1536×1024（元の大きさのまま）。元の大判PNG（約2.6〜2.9MB）から、約0.3MBに縮めています。
- 元の大判画像は作者のMacにあり、リポジトリには入れません。
