# fictional-towns

架空の街（例：U町3丁目）を作り込んでいくための作業用リポジトリです。

## 構成

- `towns/` … 街ごとのファイル。1街1ファイル（例：`towns/u-machi-3-chome.md`）
- `templates/town-template.md` … 新しい街を作るときのひな形
- `notes/` … 設定の検討メモや、ボツ案の置き場

## 進め方

1. `templates/town-template.md` をコピーして `towns/` に置き、街の名前を付ける。
2. 「地理・歴史・住民・店・交通」の順に、少しずつ埋めていく。
3. 設定同士の矛盾が出たら、`notes/` に整理して決め直す。

## 注意

- 実在の地名・店名・人物と一致しないよう、必要に応じて確認する。
- 市の業務で得た個人情報は、ここには入れない。
