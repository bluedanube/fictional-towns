# 画像の置き場

採用した画像だけを入れます。元の大判画像は作者のMacにあり、リポジトリには入れていません。

## 形式と大きさ
- **大判のイラスト（WebP、品質90）**：見た目を保ちつつ容量を抑えるため。
  - 縫い街の連作：1536×1024。元のPNG（約2.6〜2.9MB）から、約0.3MBに縮小。
  - 魔法少女の表・裏：768×1024。元のPNG（約1.4〜1.6MB）から、約0.12MBに縮小。
- **住人のアイコン（GIF のまま）**：46×46 のアニメーション GIF。すでに約2KBと小さいため、変換していません。
